# RADAR 本地部署研究预览 v0.1.0

四种部署配置沿用同一套RADAR训练权重，保留CPU拼接，不接小LLM，不重新训练，不做结构剪枝。GPU FP32是工程基线，不是纯CPU推理。

138例同配置、四版本共同成功病例中，相对同例FP32的平均绝对分数差：普通FP16与Compact均为 **0.000747**，TensorRT为 **0.001018**。这是分数一致性MAE，不是训练损失、临床准确率或146病种独立验证。

普通FP16与Compact在197个共同成功病例中，包含N/A位置的评分向量完全一致。Compact检查点去掉训练状态，693个模型张量保持原样；文件522.2MB，原文件1566.0MB。四配置不是四个重新训练的模型。

整体验证200例，800项有效记录中790成功、10失败；197例四版本全部成功。10项失败集中3例：8项CPU内存预检、1项运行中RAM保护、1项TensorRT深度224超过192上限。旧失败尝试与复测分别保留来源。138例整CT耗时/独立显存中位数：FP32为38.17秒/5.70GiB，普通FP16为30.60秒/6.08GiB，Compact为37.40秒/4.34GiB，TRT为34.36秒/3.13GiB。显存是每例采样峰值的中位数。

平均值之外有少量大分差：本次普通FP16/Compact最大0.178357，TRT最大0.491174；全200例历史FP16还包含先前已发现的0.379382。英文README同时列出异常频数和失败。成功向量有效项102–146，N/A未填零。100随机＋100覆盖补充的方案不能称为独立临床验证；AMOS20是已暴露开发/回归数据。

公开目录不含CT、患者表、临床原文、患者级预测、登录凭据或厂商DLL。英文README提供四配置命令。新的可移植CLI做静态/导入/路径/哈希核查，未在新CLI上重跑200例；表中数据来自冻结Windows适配器。

原权重、FP32计算策略、CPU拼接及固定146项主路径保持不变，无进程显存配额，保留系统RAM保护。TensorRT plan限于构建环境，范围外输入明确报错。自定义查询高级接口及GUI未被本预览替换。CC BY-NC-SA4.0要求署名、非商业和相同方式共享，保留第三方许可。社区研究发布不代表原作者背书，不提供新的临床效能保证。
